# Schemas

Versioned generated JSON Schemas and canonical examples will live here. The
human-readable rootless effect vocabulary is defined in the
[architecture overview](../docs/architecture/overview.md#canonical-rootless-effect-vocabulary).
ADR 0004 defines model-owned validation, canonical bytes, digest binding, and
migration. Issue #5 owns the serialized effect identifiers, versions, canonical
examples, unknown-value rejection, and migration/conformance vectors.

Do not add ad hoc unversioned interchange documents or define a second effect
taxonomy here.
