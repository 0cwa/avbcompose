# Roadmap

The canonical roadmap is [GitHub issue #1](https://github.com/0cwa/avbcompose/issues/1).
The tracker—not this summary—is authoritative for dependencies and acceptance
criteria.

| Phase | Goal | Issues |
|---|---|---|
| P0 | Architecture, threat model, schemas, toolchain, fixtures | #2–#7 |
| P1 | Offline prebuilt composition MVP | #8–#13 |
| P2 | Repo manifest and Android build semantics | #14–#18 |
| P3 | Automated updates and advanced Android domains | #19–#25 |
| P4 | Catalog, migration, signing, validation, PixeneOS cutover | #26–#30 |
| P5 | Custom-ROM discovery and evidence-based extension/split work | #31–#32 |

## Current work wave

Wave A consists of issues #2, #3, and #4. Scaffold work for #2 is present in the
repository; agents must inspect the issue and current tree to identify remaining
acceptance criteria rather than repeating completed work.
