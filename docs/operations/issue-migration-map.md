# Roadmap issue migration

The roadmap was originally staged temporarily in `0cwa/PixeneOS`. The canonical
mapping is deterministic:

```text
PixeneOS #62–#93  →  avbcompose #1–#32
new issue number = old issue number - 61
```

Each new issue links its original for provenance. Work, child issues, handoffs,
and future roadmap edits belong in the `avbcompose` tracker.
