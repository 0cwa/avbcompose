# Agent context loading

1. Read `AGENTS.md`.
2. Read issue #1.
3. Read the assigned issue and all listed dependencies.
4. Read only the package/domain ADRs required by that work.
5. Inspect handoff comments and current tests before planning.
6. Restate acceptance criteria in the PR.
7. Finish with a handoff that names the next unblocked work.

Do not use broad repository searches as a substitute for the issue's curated
context. Do use searches to verify current implementation and prevent duplicate
work.
